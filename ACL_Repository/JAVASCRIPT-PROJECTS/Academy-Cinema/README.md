# Academy Cinemas

This project is a responsive website for a fictional movie theater called Academy Cinemas, created to demonstrate the use of the Bootstrap framework for layout and styling.

## Features

*   **Now Playing:** Displays a list of movies currently playing, including posters, descriptions, and showtimes.
*   **Ticket Purchasing:** A visual interface allowing users to select a movie, showtime, and number of tickets.
*   **Contact Form:** A styled form layout for users to get in touch with the cinema.
*   **Responsive Design:** Built with Bootstrap components (Navbar, Cards, Forms) to ensure the site looks good on mobile, tablet, and desktop screens.

## Technologies Used

*   HTML5
*   CSS3
*   Bootstrap 5

## Getting Started

1.  Clone the repository to your local machine.
2.  Navigate to the project directory.
3.  Open `index.html` in your web browser to view the website.
