# ACL Repository

Welcome to my project repository. This repository serves as a central hub for my software development work, ranging from static web pages to dynamic React applications.

## Technologies Used
- **Languages:** HTML5, CSS3, JavaScript
- **Frameworks/Libraries:** React.js, Bootstrap 5

## Folder Structure

Here is an overview of the main folders and some key projects in this repository:

### `HTML-AND-CSS-PROJECTS/`
This directory contains projects built primarily with HTML5 and CSS3. These are static sites focusing on layout, design, and responsiveness.
- **Student_Portfolio**: A personal portfolio website showcasing Andy C. Liang's background, interests, and a link to his GitHub profile. It includes sections for Home, About, GitHub, and Contact, utilizing HTML, CSS, and JavaScript for features like an embedded YouTube video player.

### `JAVASCRIPT-PROJECTS/`
This directory contains projects demonstrating JavaScript functionalities and framework usage.
- **Academy-Cinema**: A responsive website for a fictional movie theater, built with HTML5, CSS3, and Bootstrap 5. It features a "Now Playing" section, a visual "Ticket Purchasing" interface, and a "Contact Form".
- **Basic JavaScript Projects**: A collection of fundamental JavaScript projects, such as `Project1_expressions_alert`, demonstrating core JavaScript concepts.

### `ReactProject/`
This directory houses applications built using the React JavaScript library.
- **my-app**: A React application (likely initialized with Create React App).
 serving as a foundation for more complex interactive user interfaces.

### `index.html`
The entry point for this repository (often used for GitHub Pages). It provides a landing page with links to the various projects hosted here, offering easy navigation to individual project details.

## Getting Started

To run these projects locally:

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url> # Replace <your-repo-url> with the actual URL of this repository.
   ```

2. **For HTML/CSS/Vanilla JavaScript Projects:**
   Navigate to the project directory (e.g., `HTML-AND-CSS-PROJECTS/Student_Portfolio/`) and open `index.html` in your web browser.

3. **For React Projects:**
   Navigate to the project folder and run:
   ```bash
   npm install
   npm start
   ```
